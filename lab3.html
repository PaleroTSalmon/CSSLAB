Laboratory 3: Styling Text, Colors, and Backgrounds

Introduction to CSS

CSS stands for Cascading Style Sheets. It is used to improve the appearance and design of HTML webpages.

CSS allows developers to customize text, colors, backgrounds, spacing, and layouts to make websites more attractive.

Purpose and Benefits of CSS

Using CSS makes webpages easier to read and navigate. It also helps create a consistent design across different pages.

  • Changes text colors and font styles.
  • Customizes webpage backgrounds.
  • Improves readability and presentation.
